Fonts used by this page (all SIL Open Font License 1.1, free for commercial use).
Each file is a subset cut to the characters the page actually uses (scripts/build-fonts.py);
the same data is also embedded as base64 in src/fonts.css so the built page never depends on these files.

pg-serif.woff2  Noto Serif SC (思源宋体), variable wght 400-900  — https://github.com/google/fonts/tree/main/ofl/notoserifsc
pg-sans.woff2   Noto Sans SC (思源黑体), variable wght 400-800   — https://github.com/google/fonts/tree/main/ofl/notosanssc
pg-fang.woff2   Zhuque Fangsong (朱雀仿宋) v0.212               — https://github.com/TrionesType/zhuque
pg-kai.woff2    LXGW WenKai Medium (霞鹜文楷) v1.530             — https://github.com/lxgw/LxgwWenKai
pg-mono.woff2   Spline Sans Mono, variable wght 400-600         — https://github.com/google/fonts/tree/main/ofl/splinesansmono
pgq-*.woff2     two-glyph helper fonts: U+0022 drawn as the curly quotes of the families above
