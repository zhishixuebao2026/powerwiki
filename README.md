# 衡天⊙ PowerWiki (v3.0)

基于 **《衡天⊙ 多维战力量级体系（第三版）》**（`衡天量级体系【第三版·最新】.md`）与 **《材质与破坏能量数据库（第二版）》** 构建的多维战力评定与工程物理破坏参考站。

## 核心特性

1. **量级分类（97 正式档 + 待定兜底 · 严格从小到大排列）**
   - 完整覆盖从 `⊙虫`（昆虫级，`< 10⁻⁴ J`）到 `⊙天·最`（论天最上，莱茵哈特—伯克利基数）的全部标尺与过渡带。
   - 严格按 **量级从小到大（`#01 → #97`）** 递增排布，支持 **分区卡片**、**连续天梯** 与 **紧凑总表** 三种视图，并展示第三版 **1.5 节「完整书写」推荐展开格式**。
2. **角色档案分类（首字母 A–Z & 量级从小到大双排序）**
   - 原生支持 `破 · 控 · 域 · 御 · 速 · 算 · 性` 七维独立展示、浑仪星盘图、第三版 **完整书写结论** 与 `〔实〕〔下〕〔推〕〔隐〕〔缺〕` 五级证据可信度高亮。
   - 支持 **按量级从小到大 ↑** 与 **按角色首字母 A–Z** 两种排序方式自由切换。
3. **两部标准典籍全文无删减展示**
   - `rules.html`：《衡天⊙ 多维战力量级体系（第三版）》全文直出（1,445 行原文无删减，含第三版新增完整书写原则、0.14.2 归因与知情度审查、超长篇自行通读流程、7.9 层级轴必检等）。
   - `materials.html`：《材质与破坏能量数据库（第二版）》全文直出（416 行原文无删减，宽屏/横向滚表适配）。
4. **全站即时搜索（`Ctrl + K` / `/`）与独立检索中心（`search.html`）**
   - 零外部依赖本地索引（`static/js/search-index.js`），毫秒级检索全部角色、量级、第三版规则条款与材质能量表。
5. **浏览进度保存与智能返回键**
   - 自动记录文档阅读百分比与章节位置，再次打开弹出 **断点续读提示条**，首页与顶部导航栏提供 **阅读进度与浏览足迹面板**。
   - 内置会话级智能 `‹ 返回` 栈（自动还原上一页滚动位置，无历史时回退至逻辑上级页面）与带环形进度条的回到顶部按钮。

## 目录结构

```text
powerwiki/
├── build_site.py              # 零依赖 Python 3 静态站生成器 (v3.0)
├── data/
│   ├── docs/
│   │   ├── 衡天量级体系【第三版·最新】.md
│   │   └── 材质与破坏能量数据库（新）.md
│   ├── tiers.json             # 98 个量级结构化定义与全链条顺序
│   └── characters.json        # 正式角色库与第三版完整书写演示样例
├── static/
│   ├── css/style.css          # 黑曜浑仪 / 浅色纸本双主题极简样式系统 (v4.0)
│   ├── js/app.js              # 120fps 滚动架构、排序、搜索、进度与智能返回引擎
│   └── js/search-index.js     # 自动生成的全站检索数据包
├── index.html                 # 首页
├── tiers.html                 # 量级分类页（从小到大排列）
├── tier/*.html                # 各量级独立详情页（98 页）
├── characters.html            # 角色分类页（首字母 A–Z & 量级从小到大）
├── character/*.html           # 各正式角色独立详情页（录入后自动生成）
├── rules.html                 # 《衡天⊙ 多维战力量级体系（第三版）》全文页
├── materials.html             # 《材质与破坏能量数据库（第二版）》全文页
└── search.html                # 全站检索中心页
```

## 维护与重新构建

修改 `data/characters.json`、`data/tiers.json` 或更新 `data/docs/*.md` 后，在仓库根目录执行：

```bash
python3 build_site.py
```

所有生成的静态页面均使用显式 `.html` 纯相对路径，可直接托管于 **GitHub Pages**、**raw.githack.com** 或任意静态服务器。
