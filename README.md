# 衡天⊙ PowerWiki (v6.4)

基于 **《衡天⊙ 多维战力量级体系（第四版）》**（`衡天量级体系【第四版·最新】.md`）与 **《材质与破坏能量数据库（第二版）》** 构建的多维战力评定与物理破坏参考百科。

## 核心特性

1. **两大核心分类大页面（与基准规则原文明确区分）**
   - **量级分类大库（`tiers.html` · 97 正式档 + 待定兜底）**
     - 按真实物理与数学尺度划分为 10 个连续阶段（微观与个体建筑阶 → 城镇至地表阶 → 行星至恒星阶 → 星际过渡带 A/B → 恒星系阶 → 星团至宇宙阶 → 广义无限 FGH → 论外与论天阶 → 待定档），内置可交互 **6 段跨度光谱格**。
     - 严格按 **量级从小到大（`#01 → #97`）** 单向递增排布，支持 **分阶卡片**、**连续天梯** 与 **紧凑总表** 三种视图，全 98 档均配有独立静态规格页（`tier/<slug>.html`）。
   - **角色战力档案库（`characters.html` · 首字母 A–Z & 量级从小到大双排序）**
     - 支持 **按量级从小到大 ↑** 与 **按角色首字母 A–Z** 双模式实时切换，点击角色卡片进入专属独立档案页面 `character/<slug>.html`。
     - **图片真实尺寸与比例自适应**：构建期自动检测每张角色立绘/概念图与正文测量配图的真实 `width × height` 与横竖比例，采用无裁切比例自适应画框展示。
     - 当前已收录：
       - **御兔（《非人学园》）**（`character/yutu.html`，主档 `⊙城△〔实〕` 归入 `#30 强爆城级` `tier/city-strong.html`，273 行原文无删减 + 2 张轨道火球拟合测量图 + 官方全身立绘）。
       - **弗坦（《诡秘地海》）**（`character/futan.html`，主档 `⊙宇△（元·多，至少十几）〔下〕` 归入 `#80 强宇宙级` `tier/universe-strong.html`，441 行原文无删减 + 克苏鲁古神油画风竖幅配图）。

2. **基准规则原文双卷（`rules.html` & `materials.html` · 典籍卷宗阅读器）**
   - 采用区别于分类目录大页的 **双卷典籍卷宗阅读器（Codex Reader）** 布局，支持顶部卷一/卷二切换、目录实时联动（ScrollSpy）、页内词句定位、字号缩放与宽屏表格模式：
   - **卷一（`rules.html`）**：《衡天⊙ 多维战力量级体系（第四版）》全文无删减（1,474 行，129 节目录）。
   - **卷二（`materials.html`）**：《材质与破坏能量数据库（第二版）》全文无删减（416 行，35 节目录）。

3. **全站即时搜索（`Ctrl + K` / `/`）与独立检索中心（`search.html`）**
   - 零外部依赖本地索引（`static/js/search-index.js`），毫秒级检索全部 98 个量级、已收录角色（含定级原文全部小节）、第四版规则条款与材质破坏比能表。

4. **无感浏览状态缓存、智能返回栈与 `0ms` 即时侧滑导航抽屉**
   - 静默缓存各页面滚动位置（`scrollY`）、排序方式（`A–Z` / `从小到大`）、筛选区间、视图模式与阅读偏好，进入子页面后返回自动恢复状态与位置。
   - 独立顶层侧滑导航抽屉（`#site-drawer`）采用头部零依赖即时绑定，不受离线检索脚本加载与毛玻璃层叠上下文影响。

## 目录结构

```text
powerwiki/
├── build_site.py              # 零依赖 Python 3 静态站生成器 (v6.4)
├── data/
│   ├── docs/
│   │   ├── characters/        # 角色定级 Markdown 完整原文（御兔、弗坦等）
│   │   ├── 衡天量级体系【第四版·最新】.md
│   │   └── 材质与破坏能量数据库（新）.md
│   ├── tiers.json             # 98 个量级结构化定义与连续尺度阶段
│   └── characters.json        # 角色档案数据集与图片映射
├── static/
│   ├── img/
│   │   ├── characters/        # 角色无裁切自适应立绘与帧测量标注图
│   │   └── *.jpg              # 主题底板插画
│   ├── css/style.css          # 响应式排版、分类大库与典籍阅读器样式系统
│   ├── js/app.js              # 状态缓存、双模排序、全站检索与 ScrollSpy 引擎
│   └── js/search-index.js     # 自动生成的全站离线检索数据包
├── index.html                 # 首页总览
├── tiers.html                 # 量级分类大页（从小到大排列）
├── tier/*.html                # 各量级独立详情页（98 页）
├── characters.html            # 角色分类大页（首字母 A–Z & 量级从小到大）
├── character/*.html           # 各角色独立定级档案页（全文无删减）
├── rules.html                 # 卷一：《衡天⊙ 多维战力量级体系（第四版）》全文页
├── materials.html             # 卷二：《材质与破坏能量数据库（第二版）》全文页
└── search.html                # 全站检索中心页
```

## 维护与重新构建

修改 `data/characters.json`、`data/tiers.json` 或更新 `data/docs/**/*.md` 后，在仓库根目录执行：

```bash
python3 build_site.py
```

所有生成的静态页面均使用显式 `.html` 纯相对路径，可直接托管于 **GitHub Pages**、**raw.githack.com** 或任意静态服务器。
