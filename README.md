# 衡天⊙ PowerWiki (v2.0)

基于 **《衡天⊙ 多维战力量级体系（第二版）》** 与 **《材质与破坏能量数据库（第二版）》** 构建的多维战力评定与工程物理破坏参考站。

## 核心特性

1. **量级分类（97 正式档 + 待定兜底）**
   - 完整覆盖从 `⊙虫`（昆虫级，`< 10⁻⁴ J`）到 `⊙天·最`（论天最上，莱茵哈特—伯克利基数）的全部标尺与过渡带。
   - 支持 **按量级从小到大 ↑**、**按量级从大到小 ↓** 与 **按拼音首字母 A–Z**（支持核心代字与完整名称双模式）自由切换，并提供卡片网格与紧凑总表双视图。
2. **角色档案分类（七维评定）**
   - 原生支持 `破 · 控 · 域 · 御 · 速 · 算 · 性` 七维独立展示与 `〔实〕〔下〕〔推〕〔隐〕〔缺〕` 五级证据可信度高亮。
   - 支持 **按角色首字母 A–Z** 与 **按主档量级从小到大 / 从大到小** 排序，内置 6 组体系书写演示样例。
3. **两部标准典籍全文无删减展示**
   - `rules.html`：《衡天⊙ 多维战力量级体系（第二版）》全文直出（121 个章节锚点、目录同步高亮、跨文档引用互链）。
   - `materials.html`：《材质与破坏能量数据库（第二版）》全文直出（34 个章节锚点、移动端可横向滚动数据表）。
4. **全站即时搜索（`Ctrl + K` / `/`）与独立检索中心（`search.html`）**
   - 零外部依赖本地索引（`static/js/search-index.js`），毫秒级检索全部量级、角色、规则条款与材质能量表。
5. **浏览进度保存与智能返回键**
   - 自动记录文档阅读百分比与章节位置，再次打开弹出 **断点续读提示条**，首页与顶部导航栏提供 **阅读进度与浏览足迹面板**。
   - 内置会话级智能 `‹ 返回` 栈（自动还原上一页滚动位置，无历史时回退至逻辑上级页面）与带环形进度条的回到顶部按钮。

## 目录结构

```text
powerwiki/
├── build_site.py              # 零依赖 Python 3 静态站生成器
├── data/
│   ├── docs/
│   │   ├── 衡天量级体系（新）.md
│   │   └── 材质与破坏能量数据库（新）.md
│   ├── tiers.json             # 98 个量级结构化定义与双向拼音索引
│   └── characters.json        # 正式角色库与体系书写演示样例
├── static/
│   ├── css/style.css          # 深空浑仪 / 浅色星历双主题样式表
│   ├── js/app.js              # 排序、搜索、阅读进度与智能返回交互引擎
│   ├── js/search-index.js     # 自动生成的全站检索数据包
│   └── img/                   # 站点主题横幅插画
├── index.html                 # 首页
├── tiers.html                 # 量级分类页
├── tier/*.html                # 各量级独立详情页（98 页）
├── characters.html            # 角色分类页
├── character/*.html           # 各正式角色独立详情页（录入后自动生成）
├── rules.html                 # 《衡天⊙ 多维战力量级体系（第二版）》全文页
├── materials.html             # 《材质与破坏能量数据库（第二版）》全文页
└── search.html                # 全站检索中心页
```

## 维护与重新构建

修改 `data/characters.json`、`data/tiers.json` 或更新 `data/docs/*.md` 后，在仓库根目录执行：

```bash
python3 build_site.py
```

所有生成的静态页面均使用显式 `.html` 纯相对路径，可直接托管于 **GitHub Pages**、**raw.githack.com** 或任意静态服务器。
