# 衡天⊙ PowerWiki (v6.2)

基于 **《衡天⊙ 多维战力量级体系（第四版）》**（`衡天量级体系【第四版·最新】.md`）与 **《材质与破坏能量数据库（第二版）》** 构建的多维战力评定与工程物理破坏参考站。

## 核心特性

1. **量级分类（97 正式档 + 待定兜底 · 严格从小到大排列）**
   - 完整覆盖从 `⊙虫`（昆虫级，`< 10⁻⁴ J`）到 `⊙天·最`（论天最上，莱因哈特—贝克莱基数）的全部标尺与过渡带。
   - 严格按 **量级从小到大（`#01 → #97`）** 递增排布，支持 **分阶卡片**、**连续天梯** 与 **紧凑总表** 三种视图，全 98 档均配有独立静态规格页（`tier/<slug>.html`），并自动标记档位下已收录的角色数量。
2. **角色档案分类（首字母 A–Z & 量级从小到大双排序 · 全独立页面 + 无删减原文展示）**
   - 支持 **按量级从小到大 ↑** 与 **按角色首字母 A–Z** 双模式排序，点击角色进入专属独立档案页面 `character/<slug>.html`。
   - 支持完整 Markdown 定级档案全文无删减渲染、章节目录实时联动（ScrollSpy）、官方角色立绘展示框与测量标注图（`<figure class="md-figure">`）内嵌展示。
   - 当前已收录：**御兔（《非人学园》）**（`character/yutu.html`，主档 `⊙城△〔实〕` 归入 `#30 强爆城级` `tier/city-strong.html`，273 行定级原文无删减 + 2 张轨道火球拟合测量标注图 + 官方双形态立绘）。
3. **两部标准典籍全文无删减展示**
   - `rules.html`：《衡天⊙ 多维战力量级体系（第四版）》全文直出（1,474 行原文无删减，含第四版新增 `10.8 标注图与动图处理`、完整书写原则、0.14.2 归因与知情度审查、超长篇自行通读流程、7.9 层级轴必检等）。
   - `materials.html`：《材质与破坏能量数据库（第二版）》全文直出（416 行原文无删减，宽屏/横向滚表适配）。
4. **全站即时搜索（`Ctrl + K` / `/`）与独立检索中心（`search.html`）**
   - 零外部依赖本地索引（`static/js/search-index.js`），毫秒级检索全部量级、角色（含角色定级原文各章节）、第四版规则条款与材质能量表。
5. **无感浏览状态缓存与智能返回栈**
   - 自动在浏览器本地缓存各页面的滚动位置（`scrollY`）、激活的排序方式（`A–Z` / `从小到大`）、筛选区间、视图模式与阅读字号，进入子页面后点击 `← 返回` 或浏览器后退即可瞬间还原之前的浏览状态与位置。

## 目录结构

```text
powerwiki/
├── build_site.py              # 零依赖 Python 3 静态站生成器 (v6.2)
├── data/
│   ├── docs/
│   │   ├── characters/        # 角色定级 Markdown 完整原文（如 御兔（非人学园）衡天定级.md）
│   │   ├── 衡天量级体系【第四版·最新】.md
│   │   └── 材质与破坏能量数据库（新）.md
│   ├── tiers.json             # 98 个量级结构化定义与全链条顺序
│   └── characters.json        # 角色档案数据集与立绘/标注图映射
├── static/
│   ├── img/
│   │   ├── characters/        # 角色官方立绘、头像与帧测量标注图
│   │   └── *.jpg              # 羽化融合暗调天体与物理美学插画底板
│   ├── css/style.css          # 统一网格与排版视觉样式系统
│   ├── js/app.js              # 无感浏览状态缓存、排序、检索与 120fps ScrollSpy 引擎
│   └── js/search-index.js     # 自动生成的全站检索数据包
├── index.html                 # 首页
├── tiers.html                 # 量级分类页（从小到大排列）
├── tier/*.html                # 各量级独立详情页（98 页）
├── characters.html            # 角色分类页（首字母 A–Z & 量级从小到大）
├── character/*.html           # 各角色独立定级档案页（全文无删减）
├── rules.html                 # 《衡天⊙ 多维战力量级体系（第四版）》全文页
├── materials.html             # 《材质与破坏能量数据库（第二版）》全文页
└── search.html                # 全站检索中心页
```

## 维护与重新构建

修改 `data/characters.json`、`data/tiers.json` 或更新 `data/docs/**/*.md` 后，在仓库根目录执行：

```bash
python3 build_site.py
```

所有生成的静态页面均使用显式 `.html` 纯相对路径，可直接托管于 **GitHub Pages**、**raw.githack.com** 或任意静态服务器。
