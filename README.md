# 衡天⊙ PowerWiki (v5.0 · Obsidian Celestial Archive)

基于 **《衡天⊙ 多维战力量级体系（第三版）》**（`衡天量级体系【第三版·最新】.md`）与 **《材质与破坏能量数据库（第二版）》** 构建的多维战力评定与工程物理破坏参考站。

## 核心特性

1. **量级分类（97 正式档 + 待定兜底 · 严格从小到大排列）**
   - 完整覆盖从 `⊙虫`（昆虫级，`< 10⁻⁴ J`）到 `⊙天·最`（论天最上，莱因哈特—贝克莱基数）的全部标尺与过渡带。
   - 严格按 **量级从小到大（`#01 → #97`）** 递增排布，支持 **分阶卡片**、**连续天梯** 与 **紧凑总表** 三种视图，全 98 档均配有独立静态规格页（`tier/<slug>.html`）。
2. **角色档案分类（首字母 A–Z & 量级从小到大双排序 · 全独立页面）**
   - 支持 **按量级从小到大 ↑** 与 **按角色首字母 A–Z** 两种排序方式自由切换。
   - 点击任意角色直接进入 **专属独立角色档案界面（`character/<slug>.html`）**，完整呈现第三版 **1.5 完整书写结论**、`破 · 控 · 域 · 御 · 速 · 算 · 性` 七维分项评定、`〔实〕〔下〕〔推〕〔隐〕〔缺〕` 五态证据标识及主档基准对照。
3. **两部标准典籍全文无删减展示**
   - `rules.html`：《衡天⊙ 多维战力量级体系（第三版）》全文直出（1,445 行原文无删减，含完整书写原则、0.14.2 归因与知情度审查、超长篇自行通读流程、7.9 层级轴必检等）。
   - `materials.html`：《材质与破坏能量数据库（第二版）》全文直出（416 行原文无删减，宽屏/横向滚表适配）。
4. **全站即时搜索（`Ctrl + K` / `/`）与独立检索中心（`search.html`）**
   - 零外部依赖本地索引（`static/js/search-index.js`），毫秒级检索全部角色独立页面、量级、第三版规则条款与材质能量表。
5. **无感浏览状态缓存与智能返回栈**
   - 自动在浏览器本地缓存各页面的滚动位置（`scrollY`）、激活的排序方式（`A–Z` / `从小到大`）、筛选区间、视图模式与阅读字号，进入子页面后点击 `← 返回` 或浏览器后退即可瞬间还原之前的浏览状态与位置。

## 维护与重新构建

修改 `data/characters.json`、`data/tiers.json` 或更新 `data/docs/*.md` 后，在仓库根目录执行：

```bash
python3 build_site.py
```

所有生成的静态页面均使用显式 `.html` 纯相对路径，可直接托管于 **GitHub Pages**、**raw.githack.com** 或任意静态服务器。
