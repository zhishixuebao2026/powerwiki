# 苏昼（怪物被杀就会死）衡天定级

> 条目版本：2026-11-16（当日修订：采用同一系列的设定，综合量级上调）
>
> 对象是阴天神隐《怪物被杀就会死》的主角苏昼，号「原初烛昼」。以本书为主。《高天之上》的后记写明它和本书在同一个多元宇宙，时间早八百万年；那本书里关于这个多元宇宙的设定一并采用，书中人物的战绩不算到苏昼头上。
>
> 阅读方式：本书约 586 万字，未通读。逐段读过的有：第十八卷（终卷）的序、第一至第五章、第十六章、第十八章、第二十章；第二十一至第二十五章与结局 EX 篇的关键段落；番外中、番外下。《高天之上》读了第 1091 章相关段落和后记。其余部分按合道、洪流、超越者、多元宇宙、无限、可能性、自然数、幂集等词检索后读了命中段落。两本书的中前期没有逐段读，可能漏掉具体战绩，但不影响上限的判断。

## 对象与作品

| 项目 | 内容 |
|---|---|
| 作品 | 《怪物被杀就会死》，阴天神隐著，起点中文网，完本，共十八卷 |
| 同一系列 | 《高天之上》（同一多元宇宙，早八百万年），另有《燃钢之魂》《天命皆烬》《永镇天渊》 |
| 对象 | 苏昼，原初烛昼。终卷开头已是洪流，后成为超越者，结局被称为「革新之原型」 |
| 世界 | 封印多元宇宙：由「伟大封印」衍生出的多元宇宙，有众多不同的「多元基盘」与世界群 |
| 境界 | 合道（与一个宇宙的大道相合）→ 合道巅峰 → 洪流（多元宇宙级）→ 超越者 → 伟大存在（原型） |

## 量级栏

**综合量级：⊙外·三 起〔下〕（掌控式）。** 论外三线，即连续统（2^ℵ₀）起，掌控式，只能确认至少如此。依据分两步：

- **作用的对象是一个多元宇宙的整体。** 他对整个封印多元宇宙出手：多元宇宙真灵发动全域删除时，他的力量 "跟随着白色闪电涌入多元宇宙的所有宇宙时空"；最终他修复伟大封印，"重新设立了多元宇宙的新秩序"。
- **这个多元宇宙里写出结构的最高一档是连续统。** 本书写了可能性怎样一种种分出来、又作为平行世界留存；《高天之上》写明星神造出 "无限且不可数" 的宇宙，并交代了生成方式。见第二节。

**保底量级：⊙外·门〔下〕（创造式）。** 论外门槛，即可数无限。依据是他把「烛昼天」从多元宇宙的雏形升华成真正的多元宇宙，其中宇宙数量 "视作自然数的集合N"。

**位格**：

- **存在规模：外·三〔下〕。** 叙述说在衍生轴上 "苏昼和封印多元宇宙，是一般‘大’的。都是一个点"，他的存在规模与这个多元宇宙相同。
- **层级轴（结构标注）。** 多元宇宙在「泛无限多元衍生轴」上是一个点，超越者是线，伟大存在是构成坐标系的轴。苏昼终局是超越者，结局称他为「革新之原型」。这一层的规模见第四节，倍率〔缺〕。
- **计算层级：0′〔下〕。** 0′ 指在有限时间里完成可数无限步并得到结果。依据是「尽远道」能跳过无限的重复直达结局；叙述说洪流能 "完全知晓这个多元宇宙中所有生命的一切可能性"。

**特性**：

- 无限力，以及「无限」「永恒」两种要素；
- 不灭魂：不承认就能把攻击化为无；
- 尽远道：念动即达，跳过重复；
- 轮回印；
- 分化出持有无限力的化身，同时投入所有宇宙；
- 造出多元宇宙。

**设定宣称**（不参与定级）：

- 多元宇宙包含「所有可能与不可能」，其中「不可能」的部分；
- 超越者能把整个多元宇宙 "随手镇压"；
- 「绝对无限」「超越无限」一类称号；
- 《高天之上》里 "超越人类逻辑乃至于一切逻辑的‘数学理念宇宙’"；
- 他 "寻遍整个封印多元宇宙与伟大封印两个方程组值域（-∞，+∞）中每一个点"：数的是位置，不是一个个完整的结构。

**可信度**：中。作为和结构多出自全知叙述；连续统一档有两本书各自的写法互相印证。但「无限」一词几乎每页出现，大多是修饰，只有少数几处给出了可以核对的结构。

| 维度 | 记录 |
|---|---|
| 控（整体掌控） | 外·三 起〔下〕（掌控式）：对封印多元宇宙的整体行动，见第三节 |
| 破（破坏） | 没有对一个多元宇宙整体的破坏。单次攻击的范围写作「无限大」，但没有可计数的对象 |
| 域（影响） | 隔着世界抓走合道巅峰，连同其回溯到过去的本体与全部化身 |
| 御（防御） | 不灭魂；穷天梦的无限层封印困不住他，最后是被另一股力量撞出了封印 |
| 性（特性） | 见上 |

## 用语说明

| 代字或标签 | 全称与含义 |
|---|---|
| 外·门 | 论外门槛：可数无限（ℵ₀），能一个个编号、没有最后一个 |
| 外·三 | 论外三线：连续统（2^ℵ₀），一个可数无限集合的全体子集那么多 |
| 外·二 | 论外二线：连续统的全体子集（2 的 2^ℵ₀ 次方）及以上 |
| 起〔下〕 | 从这一档起，至少如此 |
| 掌控式 | 对一个整体连同其中的一切接管、维持或重新设定 |
| 创造式 | 造出这一规模的整体 |
| 位格 | 存在规模、层级、计算层级里证据过关的部分；与综合量级并列，互不推出 |
| 设定宣称 | 只有称号或总括、没有指出对什么做成了什么的说法，单列，不参与定级 |
| 〔下〕〔缺〕 | 下限；没有可用的数据 |

## 一、书里的世界层次

| 层次 | 原文 |
|---|---|
| 宇宙 | "宇宙，指的是一切空间，时间及内部万有。其时间无尽永前，空间无界永在" |
| 世界群 | 同类宇宙聚在一起，"进而逐渐形成虚空世界群"；"一个世界群里面有一两个合道就差不多了" |
| 封印多元宇宙 | "哪怕是无限的宇宙，在这封印多元中，也不过是沧海一粟"；不同多元基盘的世界有多少，"答案是无限！" |
| 多元宇宙的雏形 | 洪流能造的东西。烛昼天、太一混元体内的「太极时空」都属于这一类 |
| 泛无限多元衍生轴 | "诸多不同的多元宇宙借它来进行对应对照，存在于它之中"；多元宇宙在这里是一个点，超越者是 "无限延伸的方程组"，伟大存在是轴 |
| 象形之域 | 衍生轴之外，"无法用点，线和面来规范" 的区域 |

境界的定义也来自叙述：合道巅峰 "仅仅是祂们宇宙的苍天化身"；"洪流强者，在没有其他同级强者的干涉下，能影响整个多元宇宙，将多元宇宙塑造成自己想要的模样，甚至是自己创造一个多元宇宙"。

**系列的联系。** 《高天之上》后记交代："在怪杀中有不少有关于伊恩的小彩蛋"；伊恩 "一直都在尝试去解决‘多元宇宙真灵’"，"为此，伊恩还投资了苏昼"。正文的作者附言说那本书的时间 "是怪杀的八百万年前，冰凝虚空和伟大封印把虚空冻的很结实"。两本书写的是同一个封印多元宇宙。

## 二、各层写到了什么

| 档位 | 原文写了什么 | 结论 |
|---|---|---|
| 可数无限：烛昼天 | "如若将烛昼天中的宇宙数量视作自然数的集合N，又设等差数列P1，P1.1=10x-1，P1.2=10x-2"，按这种方式把宇宙分成一组组再投射力量 | 写出了结构：宇宙一个个编号，还能按规则分成无穷多组 |
| 可数无限：穷天梦 | 梦中梦层层叠加，苏昼 "一步击碎无限层次的梦境封印"，仍在梦中；"即便是无限次的飞升，仍然还有无限高的‘相对真实’去追逐"；"每一层的梦中宇宙都是绝对真实的" | 写出了结构：层能编号，一步跨过无穷层之后上面还有层，层数没有顶；每层是一个真实的宇宙 |
| 连续统：本书的可能性 | 可能性由 "每一种选择，每一种可能，每一个基本粒子不同的迁跃，每一个人每时每刻作出的每一个随机的选择" 组成；宇宙的时间 "无尽永前"；这些可能性 "在坍塌后并没有消失，而是成为平行世界的基础"；多元宇宙 "内部包涵着无限宇宙的可能性实体" | 写出了结构：无穷多个选择点，每一种完整的组合是一种结局，作为平行世界留存，并且作为「实体」存在于多元宇宙中 |
| 连续统：《高天之上》 | 连续统假设不可判定，加上不同的假设 "就可以得到许多不同版本的‘数学’。——宇宙就是这样的‘解’"；星神 "构筑出了无法尽数的宇宙，得到了无限且不可数的解。也就是真实无限的宇宙，以及它们各自独立的无限平行时空"；泰拉被写成 "基于笛卡尔积定义下的自然数的幂集" | 写出了结构，还明说是「不可数」：把不可判定的命题逐个选真或选假，每一条完整的选法得到一个宇宙 |
| 连续统以上 | 《高天之上》的苏斯林树（"每一个链（枝）和反链都至多可数"）是一棵高为第一个不可数序数的树，大小不超过连续统；「数学理念宇宙」"超越人类逻辑乃至于一切逻辑" | 没有写出连续统的全体子集那样的结构，停在外·三 |
| 衍生轴的点、线、轴 | 多元宇宙是点，超越者是线，伟大存在是轴 | 维度式的层级关系，规模见第四节 |

## 三、苏昼做了什么

**终卷之前的位置。** 终卷开头他已是洪流，有自己的多元雏形「烛昼天」，里面关着数以百计的合道强者。

**隔界抓人。** 浑天之界的合道巅峰诸地闻曾回溯到「幽海开辟之初」，给自己塑造了过去的本体。苏昼伸手一提，"这尊合道巅峰的强者的本体，化身，分身等存在，全部都消失在了浑天之界"。

**推动浑天之界。** 浑天之界是 "作为一个无限大浑天论的宇宙" 的特殊大宇宙。他 "施施然地将浑天之界推开"，下一章说 "苏昼刚才认真推动它，却仅仅只是推动了一丝轨迹"。

**无限之拳。** "这一拳不仅仅是威力，捕获的范围也同样是无限大"。这一拳打散了数十位合道结成的阵，同时没有伤到周围任何一个世界。

**烛昼天成为多元宇宙。** 同六位洪流交战时，"那无穷无尽的囚世正在扩展，扩大，从单纯的无限囚笼化作真正的宇宙"，烛昼天 "从多元宇宙雏形，逐渐升华为真正的多元宇宙"。它一边无限膨胀，一边把五至圣顶在两个多元宇宙的屏障之间。

**全域对抗删除。** 多元宇宙真灵发动删除，"整个多元宇宙都开始了最终的删除过程"，连平行时空也被波及："那无限衍生，无限分裂的可能性也同样被感染"。苏昼按自然数集的编号分出力量，投入每一处受侵蚀的宇宙时空，"开始了一场席卷整个多元宇宙的浩大战争"。

**修复与新秩序。** 很久之后，他找到真灵痛苦的根源「伟大封印」，"将其缓缓修复，然后解开"，"然后，重新设立了多元宇宙的新秩序。成为了【超越者】。"。

**之后。** 他走遍其他多元宇宙，走出衍生轴进入象形之域，见到了伟大存在雅拉。结局说的是 "在革新之原型的帮助下"，混沌将蜕变为「可能」。

## 四、综合定级

**为什么是连续统起、掌控式。**

- **作用对象是多元宇宙的整体。** 对封印多元宇宙的两次行动都覆盖整体：一次是全域对抗删除，波及每一个宇宙时空和分裂出的可能性；一次是设立新秩序。叙述还交代洪流本来就能把多元宇宙 "塑造成自己想要的模样"。
- **结构到连续统。** 这个多元宇宙的可能性结构写到了连续统，两本书各写了一遍。按「超越者按其所超越的结构定档」，记外·三起。

**为什么不更高。**

- **连续统以上只有称号和总括。** 「一切逻辑之外的数学理念宇宙」，以及多元宇宙包含「所有不可能」，都没写出比连续统更多的东西怎样构成。苏斯林树的大小不超过连续统。
- **点、线、轴也推不过连续统。** 如果把超越者的线读作由与多元宇宙同样大的点组成，规模是连续统乘连续统，结果仍是连续统；一条线和一个平面的点数一样多，所以轴也一样。要到外·二，得写出「线上所有点的所有组合各成一个世界」，或「坐标系里一切可能的曲线都实际存在」，书里没有。这一读法本身也是在比喻上推算，所以只作说明，不进档位。
- **超越者与原型层面没有整体作为。** 苏昼没有对衍生轴整体或象形之域做过什么，单次作用的对象仍是一个多元宇宙。

**为什么不更低。**

- 本书写出了可能性的生成方式和留存方式，不是只有「所有可能性」一句话；
- 《高天之上》直接写出「不可数」，并给出由不可判定命题分出宇宙的机制，两处互相印证；
- 计数和层级都由全知叙述给出，不是角色夸口。

## 六、存疑

1. **可能性那段的出处。** 写出生成方式的那段，是宿命向苏昼展示第五乐章宇宙时的叙述；平行世界留存的规则在第二十章是一般性交代。两处合起来用，跨了一步。《高天之上》那段则是直接写出「不可数」，可以单独成立。
2. **「每时每刻」。** 若把「每一个人每时每刻作出的每一个随机的选择」读成连续时间里每一瞬都有选择，规模会更高。这是汉语的习惯说法，不这样读。
3. **作者文字的地位。** 系列联系出自《高天之上》的后记和章末作者附言，只用来确认几本书在同一个多元宇宙，不用来添加能力。评鉴所截图里作者在聊天中对穷天梦的解释，不作为正文设定。
4. **评鉴所对《天命皆烬》的概括。** 「集合论宇宙」「一阶、二阶、三阶算术」等词在《天命皆烬》原文里检索不到，那是评鉴所自己的概括，本条目不采用。
5. **「革新之原型」的地位。** 结局只用了这一称呼，没有写苏昼成为原型后的作为。
6. **中前期。** 两本书都只按关键词读，可能有具体战绩没有列入；上限不受影响。
