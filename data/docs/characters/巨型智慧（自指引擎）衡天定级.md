# 巨型智慧（自指引擎）衡天定级

> 条目版本：2026-11-15
>
> 对象是《自指引擎》里的巨型智慧，按单个个体定级；书中有名字的十余个（世界树、基歇尔、柏拉图、希尔德加德、彭特考斯特二世、山姆大叔等）写法相同，不分别立条。自称比邻星人的超越智慧体、讲述者「机械之无」放在第五节对照。
>
> 阅读方式：未通读。全书（序、二十章、跋，约十三万字）建成检索库后，细读了第五章《Event》后大半、第十章《Daemon》主体、第十八章《Disappear》、第二十章结尾和跋，以及第三章结尾、第十一章《Contact》、第十七章《Infinity》的相关段落。其余各章按关键词检索：基数、序数、集合、公理、无限、宇宙的个数、巨型智慧的能力与限度、超越智慧体、时间束。可能漏掉这些词没有覆盖到的具体事件，尤其是第一、二、四、六、七、九、十三、十五章这些故事性较强的篇目。

## 对象与作品

| 项目 | 内容 |
|---|---|
| 作品 | 《自指引擎》（Self-Reference ENGINE），圆城塔著；所据为丁丁虫中译本 |
| 对象 | 巨型智慧：人类建造的大型计算机，后来放弃电路，与自然现象合为一体 |
| 背景 | 「事件」粉碎了时空，宇宙分裂成许多个；每个宇宙由一个巨型智慧维持，彼此进行「运算战」 |
| 相关对象 | 超越智慧体（自称比邻星人的老人；书末提到的巴丰特）；机械之无（全书的讲述者，自称不存在）；詹姆、丽塔等人类 |

## 量级栏

**综合量级：⊙宇○〔下〕（掌控式）**——标准宇宙级，即整体掌控一个宇宙（按可观测宇宙计，直径约 930 亿光年，8.0×10⁷⁷ J），只能确认至少如此。依据是第五章的交代："此时此刻，宇宙依靠与各自的宇宙自然现象同一化的巨型智慧的运算保持自己的形态"。一个巨型智慧就是它那个宇宙的自然法则，宇宙连同其中的一切靠它的运算存在；第十一章还写到它们另外算出过一个没有人类的宇宙。宇宙的大小书里没有写，按通例取可观测宇宙。

**保底量级：⊙团○〔下〕（掌控式）**——星团级，约 3.3×10⁵⁹ J。去掉的是「宇宙按可观测宇宙计」这一步，改用书里唯一的尺寸：第十七章说那个宇宙 "至少已经观测到了半径30光年的地表"，直径 60 光年。

**位格**：

- 存在规模：与综合量级同档。巨型智慧 "与自然现象本身化为一体"。
- 计算层级：有限。书里明说 "超越自然现象的计算速度是不存在的"，最快的算法 "必须有着大于0的有限的最小步骤间隔"；巨型智慧的速度就是自然现象本身的速度。
- 层级轴（结构标注）：人类之上是巨型智慧，巨型智慧之上是超越智慧体。老人自称中间隔着约三十层，巨型智慧内部对这话的真假有分歧。

**设定宣称**（不参与定级）："无限接近于全能"；"事实上什么都可以做"；能造出自己搬不动的石头再搬动它；宇宙有「无数」个；某个宇宙是住着无限个人的无限平面。

**可信度**：中。综合量级靠的是叙述者对世界规则的交代，不是一场写出经过的事件；好在书里对巨型智慧的限度写得同样直白，上下都有原话可依。

| 维度 | 记录 |
|---|---|
| 控（整体掌控） | 宇○〔下〕：维持一个宇宙的形态，即该宇宙的自然法则（依据设定陈述）。改变过去是日常操作；算出过没有人类的宇宙 |
| 破（破坏） | 宇○〔推〕：由整体掌控推出。已写出的事故：时空再统合计划失败，北美中西部一带消失（范围未写） |
| 域（影响范围） | 把时空间弹道导弹造成的损害预先运算成没有发生过；溯行到人类诞生以前的过去；派个体前往比邻星系 |
| 御（防御） | 〔缺〕。首次接触超越智慧体时，至少 81 个巨型智慧受损后修复 |
| 算（计算层级） | 有限（原文自陈） |
| 性（特性） | 与自然现象同一；备份完备，不能遗忘；能投影出与人交流的形象；改写过去（已写出，见「控」）。「造出搬不动的石头再搬动」是自述，记在设定宣称 |

## 用语说明

| 代字或标签 | 全称与含义 |

| ⊙ | 综合量级标记 |
| 宇○ | 标准宇宙级：一次覆盖或整体掌控整个可观测宇宙，8.0×10⁷⁷ J |
| 团○ | 星团级的第二档：覆盖直径 50～100 光年，2.3×10⁵⁹～9.2×10⁵⁹ J |

| 设定陈述 | 叙述者对世界规则的平实交代，不是一次具体的事件，也不是人物的赞语 |
| 论外门槛 | 可数无限（ℵ₀）：无限个完整的宇宙，或与之相当的规模。本条目的对象没有到这里 |

## 概述

- **巨型智慧是「一个宇宙的自然法则」。** 这是全书对它们最明确的定位，也是综合量级的出处。
- **书里把它们的限度写得很清楚。** 它们算不动时空的修复，离全知很远，被更高的存在随手突破，最后还论证出自己已经灭绝。原话是："它们也不过是伫立在无限之前的有限之物"。
- **「无限」多数时候带着保留。** 无数的宇宙是巨型智慧的推测，书里说它难以令人信服；无限的平面和无限的人，书里说没人知道是不是真的。
- **集合论只出现过一次，是在讲理论的名字。** 第三章结尾设想终极理论会怎样一个个被推翻、改名，一路排到「ω 理论」。
- **这本书的重心在自指和叙述。** 讲述者说自己不存在，说故事讲不完。这些是关于「谁在讲、能不能讲」的话，不是关于世界有多大的话。

## 一、定级方法

**只用这一本书。** 同一位作者的其他小说是另外的作品，不并入。检索确认，本书译本里没有出现公理、独立性、强制（力迫）、实数、可数、阿列夫这些词。

**设定陈述进主档，属性不进。** 「宇宙靠它的运算维持」交代了对象对整个宇宙做什么，可以定档；「什么都可以做」「接近全能」没有指出做成了哪件事，只列出。

**带保留的话照保留读。** 原文自己加了「推测」「难以令人信服」「没人知道是不是真的」「也许」的地方，不当作确定的设定。

**引文。** 双引号内是中译本原文，章名按该译本。

## 二、世界

**事件。** 巨型智慧群把计算改成直接以自然现象进行："巨型智慧的网络，放弃了逻辑电路的堆积，与自然现象本身化为一体"。代价是 "彻底粉碎了时空构造"。是事故还是必然，"巨型智慧自身坦言自己并无头绪"。

**事件之后的世界不稳定。** 序章写那段时期："石头转眼变成了青蛙，转眼变成了牛虻"，原本是青蛙的牛虻又 "忽然想到自己是石头"。事物的身份和来历会变，过去可以改。这是世界的性状，记作特性，不带规模。

**宇宙的个数。** 第五章："根据巨型智慧的推测，在事件发生的刹那，瞬间生成了无数的宇宙"，"换言之，无限量的信息在那一刹那生成。这是难以令人信服的见解"。随后一个巨型智慧解释 "要新造无数宇宙，不需要无限的信息量"，用的是有限种瓷砖也能铺出无穷多种图案的例子。第十章的说法是 "在通常认为存在无数个的宇宙中"。

能确定的是宇宙不止一个，而且彼此交战："宇宙彻底分裂，因而在某种意义上演变成邻接各宇宙间的运算战"。有多少个，书里给的是推测和通行看法，没有给数。数量记「多个」。

**宇宙的大小。** 只有第十七章给过一处。丽塔所在的宇宙："人们认为现今的宇宙是平面的，无限延伸的平面，其上生活着数量无限的人。虽然没人知道这是不是真的，但至少已经观测到了半径30光年的地表，姑且认为它是正确的"。无限是「人们认为」，三十光年是观测到的。保底用后者。

这一章接下来的推理是：把每个人看成高维空间里的一个点，反复对半分，无限个点必然在某处越挤越密，所以 "无限相似的人是几乎可以确定存在的"。这是「无限个点必有聚集处」的论证，用到的只是「无限个人」，不涉及更大的无限。

## 三、巨型智慧能做什么

**维持一个宇宙。** "保持某种事物本身就是自然法则的工作，所以被迫从事这一工作的巨型智慧并没有不满"。书里把它和人的关系比作作者和文字："作者是化作宇宙自然法则的巨型智慧，而人类不如说更接近于被书写的文字"。詹姆所在的宇宙被称作 "这个由世界树运算的宇宙"。

**改写宇宙里的事。** 把摔成肉泥的人重构出来，"对巨型智慧而言也是轻而易举的"（这一句是说能，没有做）。实际写出来的有：

- 世界树应对来袭的导弹："将时空间间弹道导弹带来的损害预先运算成不复存在的情况，以此将之无效化"。
- 改变过去是 "巨型智慧日常执行的事情"。
- 为了赶走闯入的老人，"也有巨型智慧尝试生成没有自称比邻星人来访的宇宙，或者尝试改变到没有这一来访的过去"；书里顺带提到 "不存在人类的运算宇宙中没有出现那样的图像"，可见另算一个宇宙是做得出来的。

**群体。** "巨型智慧群可以自由计算无数的存在宇宙。那是当今宇宙的姿态"。这是全体合起来的状态，一个巨型智慧对应一个宇宙；它们之间是你死我活的关系："不摧毁他人，自己就会被摧毁"。

**记法。** 一个巨型智慧对它的宇宙是整体接管，连宇宙的形态本身都靠它维持，记控：宇○〔下〕（掌控式，依据设定陈述）。

## 四、原文写明的限度

- **有限。** "它们也不过是伫立在无限之前的有限之物"。
- **算不动时空的修复。** 世界树自己说："修正时空构造这样的作业，远远超越了巨型智慧的运算能力"；"大脑自身也不可能无限量增产"。时空再统合计划的胜算，巨型智慧给的是 "零"，后果是 "把北美西部中域一起拖下水"；后文交代北美中西部确实消失了。
- **计算有上限。** "超越自然现象的计算速度是不存在的"。
- **不全知。** "巨型智慧虽然无限接近于全能，但距离全知还很远很远"；彼此也难以知道对方在想什么。
- **有做不到的事。** "巨型智慧事实上什么都可以做，但实际上什么都没有做"，书里说其中 "便可能存在着某种制约"。伸手去取沉在恒星内核里的遗物，"还是被恒星的热量阻挡了"；围绕那颗恒星的 "一切维度操作都以失败告终"。
- **挡不住更高的存在。** 老人 "毫无征兆地闯进了多宇宙广播网"，生成新宇宙、改变过去都赶不走；希尔德加德被当成辞典使用。
- **上面还有够不到的一层。** 世界树谈拉普拉斯妖："虽然妖精破碎了，又上了一层楼梯，逃去了我们无法企及的地方"；它们的打算是 "抓住踏上逻辑阶层的妖精，把它拽下来"。基歇尔想象的是 "在逻辑阶层的尽头，广袤的沙漠在无限维度上伸展"，这一句前面写明是「在基歇尔的想象中」。
- **推出了自己的灭绝。** 第十八章，巨型智慧们得出结论 "我们似乎已经灭绝了"，并且判定无法靠改变时空来回避，因为 "预备定理第6666号证明了那种改变的不可能性"。书里的评语是："能够自由改变过去、操控时空的前所未有的存在，在这个问题上做出了极其遵循常识的判断"。
- **关于全能的那句话。** 第十八章，巨型智慧群说自己 "可以创造出自己无法移动的石头，然后又移动它"；同一句的后半是："而以那种程度的智慧规模，也只不过是可以理解自己已经灭绝的事实是无法回避的而已"。

## 五、同书其他对象（供对照）

| 对象 | 做了什么 | 记法 |
|---|---|---|
| 自称比邻星人（超越智慧体） | 突破全部防火墙闯入多宇宙广播网；巨型智慧生成新宇宙、改变过去都无法把他去掉；首次接触中至少 81 个巨型智慧受损；留下一个 "直径约为两千千米的超维度构造物"，沉在恒星内核 | 层级在巨型智慧之上，能压过宇宙级的掌控者；自身的规模没有写，未定级。「三十层」是他自己的话，书里说 "意见也有分歧" |
| 巴丰特 | 名字只在结尾出现一次，讲述者说 "我不记得听过后面那个名字"；第十四章有一尊被称作「超超超超越智慧体」的石像与少女对话，那一章是预告片式的片段 | 没有可定级的表现，未定级 |
| 机械之无（讲述者） | 自称 "完全机械地、完全决定论地运作的完全不存在"；工作是 "像这样讲述故事，然后选择停止讲述"；把巨型智慧和超越智慧体都称为敌人，说它们 "一旦找到就会把我撕碎" | 无表现，未定级。它在躲避巨型智慧，这是书里写明的位次 |
| 詹姆、丽塔、医生等人类 | 个别人有奇异的时空构造，能让巨型智慧烦恼；书末暗示巨型智慧推出灭绝的契机在他们身上 | 特性，未定级 |

**讲述者单独说明。** 跋里讲述者报出名字："我的名字是：Self-Reference Engine"，又称 "机械之无"。书名指的就是它。原文对它的交代：

- 来历："是作为一个时空构造创造出来的"；"我是一个太过复杂、无法存在的东西，因而不存在"。
- 工作：讲故事，然后停下。它讲不完："要讲述无限的故事，需要花费无限的时间"；丽塔和詹姆的故事，"我没有办法讲述它"。
- 处境："眼下我一直在逃避它们的探索"，它们指巨型智慧和超越智慧体。
- 特性："不存在的我的非存在，在原理上是完全不可知的"。

它是书里被造出来、又被书里的存在追捕的东西，原文没有把它写成站在故事外面的作者。可记的是特性（不存在、不可知、讲述），没有一件带规模的事，所以不定级；位次上它在躲巨型智慧，不记在巨型智慧之上。

## 六、综合定级

**为什么是宇宙级。** 两步都有原话：世界是一个个宇宙；一个巨型智慧维持一个宇宙的形态，是它的自然法则。

**为什么不更高。**

- **书里自己说它们是有限之物**，算力有上限，修不好时空。
- **宇宙的个数没有给。** 「无数」是推测，并被同一章的另一种解释冲淡；一个巨型智慧也只对应一个宇宙。
- **「无限的平面、无限的人」带着保留**，而且只是其中一个宇宙的通行看法；即使当真，也只是可数的无限，那一章的论证用不到更多。
- **「攀登巨大基数的阶梯」说的是理论的名字。** 原话是设想终极理论一路改名，"φ理论大约会逐渐朝向超穷序数ω理论发展"，前面是 "这是个很有趣的想象"，后面是 "阶梯之上，也许是我们无法企及的、唯有巨型智慧才能触摸到的理论世界"，再后面是 "真理即42"。这里没有写世界的结构，也没有写巨型智慧掌握了什么。
- **「故事不是良序集」说的是讲述。** 讲述者说故事之间还填着无数故事，没法按顺序讲完，所以 "让我把无限拉过来讲述它的影子还容易一些"。这是在解释为什么讲不完，没有交代有多少个宇宙。
- **书里说的是「可能的只是可能」。** 跋的原话："在这个宇宙，可能发生的事情仅仅是可能发生"。它没有说一切可能的事都已经成真。同一本书里写着不少确实做不到的事：时空修不好，围绕那颗恒星的维度操作全部失败，灭绝无法回避并且有定理证明。这不是一个「什么都成立」的世界。
- **「什么都可以做」是属性**，同一句话里就接着说它们什么都没做、可能存在制约。
- **超越智慧体更高，不等于巨型智慧更高。** 比它强的存在的规模，不能倒过来记在它名下。

**为什么不更低。**

- 「宇宙靠它的运算保持形态」是叙述者交代的规则，不是人物的赞语；
- 改变过去、抹掉导弹损害、另算一个没有人类的宇宙，都是写出来的事，与这条规则相符；
- 保底取的是书里唯一的尺寸，没有再往下压。

**对战判定。**

- 按「一个宇宙的自然法则」计：在它的宇宙里可以改写事件、改变过去；对它的宇宙之外，书里只写了与别的巨型智慧的运算战。
- 它的计算是有限的，会被更高层次的对手无视防御，也会被某些「时空构造奇异」的人拖慢。
- 「全能」一类的话不作为依据，书里自己对这个词很谨慎。

## 存疑

1. **「维持宇宙的形态」算不算整体掌控。** 综合量级系于此。若只认写出经过的事件，巨型智慧能确认的是局部的时空改写（一栋楼、一次接触），规模没有数字，综合量级无从定档。
2. **宇宙的大小。** 综合量级用了通例的可观测宇宙；保底用的三十光年出自丽塔那个宇宙，它与世界树等所在的宇宙是不是同一个、由谁维持，书里没有说。
3. **无限平面若当真。** 那个宇宙就有可数无限的人和无限的面积，维持它的巨型智慧可以记到论外门槛。原文说「没人知道这是不是真的」，没有采用。
4. **无数宇宙若当真。** 群体合计可以到可数无限个宇宙；单个巨型智慧仍是一个宇宙。
5. **译本与原文。** 所据为中译本，没有对照日文原文。「巨大基数」一词译本如此，按大基数理解；原文若另有措辞，以原文为准。
6. **没有细读的章。** 见页首。若其中写有巨型智慧针对多个宇宙的一次性作为，综合量级要相应上调。
