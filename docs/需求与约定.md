# 需求与约定

这份文件记录**用户明确提出过的要求**，以及每一条现在是怎么落实、怎么验收的。
新接一套皮肤、或者改动生成流程之前先读这里，别踩已经踩过的坑。
更新记录见 `../CHANGELOG.md`，实现细节见 `../README.md`。

## 一、硬性要求

| # | 要求（用户原话的意思） | 落实方式 | 怎么验 |
|---|---|---|---|
| 1 | 不要看源码判断效果，**自己截图看看** | 全部改动都在真实 Chromium 里跑 | `qa2/` 下的 puppeteer 脚本 + 截图，报告里贴图 |
| 2 | 给 **raw.githack** 的 branch/SHA 预览链接 | 汇报时给 `https://raw.githack.com/zhishixuebao2026/powerwiki/<SHA>/<path>` | 链接里的 SHA 必须等于当次推送的 HEAD |
| 3 | **不许手改生成的 HTML** | 只改 `build_site.py` / `static/**` / `skins/_source/**` / `data/**`，然后 `python3 build_site.py` | `git diff` 里不应出现 `skins/*/*.html` 的逐行修改，只能是重建产物 |
| 4 | 皮肤 = **换一整套页面设计**，不是换调色板 | 一套皮肤 = 一份整页 HTML + 可选 patch；`data-skin` 那种只换 token 的方案已废弃（`ad7f88d`） | 切换后版式、排版语言明显不同，不只是颜色 |
| 5 | 输入是**成品单页 HTML / 原始 ZIP**，集成由我做 | `skins/_source/<id>.html` 只放整页产物，修补一律进 `skins/patches/<id>.js` | patch 里只做必要的注入与避让 |
| 6 | **闪屏是 bug** | 首帧底色在 `<head>` 内联脚本里先刷，切皮肤不做全屏交叉淡入（`8507c08`） | 冷启动录屏 / 逐帧截图，无白闪 |
| 7 | **所有候选皮肤都要留着可切换**，不许裁剪 | `data/editions.json` 里一条不删 | 切换器里能数出全部皮肤 |
| 8 | 当前站点必须叫 **默认** | `default` 那套 `name` 固定为「默认」 | 切换器里第一项文案是「默认」 |
| 9 | 切换器必须**按页面范围** | `pages` 里登记了哪一栏 / 哪一页，才在哪一页出现 | `/rules.html` 只有 `默认 / 观象台`，`/materials.html` 只有 `默认 / 卷宗 / 星图` |
| 10 | 单页产物**不要造假分页** | 卷宗页的假翻页已撤（`6bea10a`） | 产物没有对应分卷就不出翻页器 |
| 11 | 皮肤名**从风格来**，不要沿用产物里写的名字（那是模型名） | 观象台 / 月面 / 卷宗 / 星图 | 名字能对上设计语言，见 README 的皮肤表 |
| 12 | 切换器要**小、可折叠**，且**不能压住皮肤自己的 UI** | 左下角圆点印章 + `editions.js` 实测所有固定/吸顶块后逐块避让 | 各宽度下印章与皮肤自身的底栏、侧栏、目录零重叠 |
| 13 | 整页产物必须**真正嵌进站里**，不能是单向门 | 桌面侧栏 / 移动抽屉顶部挂「站内其他栏目」，连回量级 / 角色 / 规则 / 材质 / 首页 | 点进去 200；侧栏与抽屉各挂一次 |
| 14 | 性能优化**不许削减视觉与动效** | 只删冗余请求、压首屏图片（4.2MB→0.4MB），不动观感 | 优化前后同屏截图对比一致 |
| 15 | 「全面优化美化适配」 | 排版、筛选条、滚动进入、键盘焦点环、深浅色一致 | 见 CHANGELOG 2026-11-01 / 11-02 |

## 二、验收口径（每次都跑）

- 宽度 **1440 / 768 / 390 / 320** 各测一遍：
  - `document.documentElement.scrollWidth <= innerWidth`（横向溢出 0）
  - 页面无 JS 报错、无请求失败（`pageerror` / `requestfailed`）
  - 正文字数与上一版同量级（防止整段内容没渲染出来）
  - 深浅两套主题各截一张
- 固定元素两两求交必须为 0（印章 / 底栏 / 阅读工具条 / 抽屉）。
- 整页产物高度动辄上万像素：**抽样截图**（按比例取 8～9 屏拼图），
  不要按视口逐屏跑完整页那种全量扫描。

## 三、皮肤接入的固定流程

1. 产物整页 HTML 存成 `skins/_source/<id>.html`（自包含优先）；
2. `data/editions.json` 加一条：`id / name / tag / note / source / section|pages / thumb / patch`；
   - `section` 是栏目（rules / materials / …）；
   - 只挂单页时用 `pages` 里的单页键（例如 `character-yutu`），
     并在 `default` 那条里补同名键指回原页面，保证互跳；
3. 字体缺失或有子集裁字时，构建期修（`font_rewrite` 或 patch 里换站内字体）；
4. 需要站内导航 / 避让 / 小样式修，全写进 `skins/patches/<id>.js`；
5. `python3 build_site.py` 重建，按第二节验收，再补 CHANGELOG 与 README 皮肤表。
